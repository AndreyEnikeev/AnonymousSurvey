# Журнал расхождений с ЛР №2

## D-01. LLM-оркестратор, внешний провайдер, эндпоинт O-11 — не реализуются
- **В ЛР №2:** Контейнер C-06, C-12, эндпоинт O-11.
- **В реализации ЛР №3:** отсутствуют. Таблица `llm_classifications` оставлена.
- **Причина:** п. 4 ЛР №3 прямо исключает интеграцию с языковой моделью.

## D-02. Внешний сервис почтовых уведомлений → MailHog
- **В ЛР №2:** R-06 / C-13.
- **В реализации ЛР №3:** MailHog — локальная SMTP-заглушка.
- **Причина:** п. 4 ЛР №3 разрешает заменять коммерческие сервисы локальными заглушками.
